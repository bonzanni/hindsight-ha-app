# Hindsight — Home Assistant Add-on

Runs [Hindsight](https://github.com/vectorize-io/hindsight) agent memory
(API + control-plane UI + embedded PostgreSQL) as a Home Assistant add-on,
optimized for low-power amd64 hosts (e.g. Intel N150). Local embeddings and
reranking; an OpenRouter reasoning LLM; memory persisted under `/data`.

See `hindsight/DOCS.md` for configuration and usage.
